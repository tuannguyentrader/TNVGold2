# GoldPulse Page Topology

1. Disclaimer banner: dismissible, flow content, links to footer.
2. Hero header: TNV GoldPulse brand, BETA badge, session/refresh status, license controls, manage modal, notification modal.
3. Pro upgrade banner: flow content, opens upgrade modal.
4. Action ticker: status message, share-to-clipboard button, notification modal.
5. Dashboard top row: responsive two-column desktop layout. Metrics grid and AI analysis are grouped in a gold-bordered panel; sponsor/news and live price chart occupy the right column.
6. Technical indicators: six compact cards with informational tooltips.
7. Gold Session Flow: click-driven tabs, checkbox visibility toggles, timeframe/range controls, SVG hover inspector.
8. Recent Gold Pulse History: responsive horizontally scrollable data table.
9. Regulatory footer: disclosure and policy links.
10. Fixed subscribe bar: dismissible and modal-driven.

Desktop uses a max-width dashboard with 3-column metric cards and two main columns. At mobile width the flow layout stacks and controls wrap. The fixed subscribe bar remains visible above the viewport bottom until dismissed.
